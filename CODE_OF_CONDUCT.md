# Code of conduct

Remik welcomes participation regardless of background, identity, experience, or ability. This policy applies in project issues, pull requests, reviews, other project-managed spaces, and when someone represents the project publicly.

## Expected conduct

Be respectful and specific. Critique code and ideas without attacking people, explain technical disagreements, accept corrections, and allow others time to respond. Respect people's privacy, names, pronouns, and boundaries. Help keep discussions accessible and relevant to the work.

Harassment, discrimination, sexualized attention, threats, doxxing, sustained personal attacks, and retaliation against reporters are unacceptable. Do not publish private communications or personal information without consent. Repeated disruption after a request to stop is also a violation.

## Reporting and enforcement

The conduct contact is [@oscarlaw](https://github.com/oscarlaw), the maintainer listed in [MAINTAINERS.md](MAINTAINERS.md). Use a contact method explicitly published on that profile if available; no dedicated confidential conduct inbox is designated. If none is available, a public request to arrange private contact should contain no personal details. A GitHub issue is public, and GitHub private vulnerability reporting is for security vulnerabilities, not a general conduct inbox.

For threats, abuse, or concerns involving the maintainer that cannot safely use this route, use [GitHub's abuse-reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-abuse). The project currently has no independent internal appeals contact. For immediate danger, use the relevant local emergency services rather than waiting for project moderation.

Reports should identify the conduct, relevant links or evidence, and any safety or privacy concerns. Maintainers will limit disclosure to what is needed to investigate and respond, explain the decision where appropriate, and avoid retaliation. There is no guarantee of absolute confidentiality or immediate availability.

Responses depend on severity and repetition. They can include requesting an edit or apology, removing content, issuing a warning, restricting participation temporarily, or banning participation. Credible threats or severe harassment can justify immediate restrictions. A participant may ask for reconsideration with new information through the same safe contact route; conflicts of interest should be disclosed, and the limits of the current single-maintainer process should be made explicit.
